## Critérios de evidência

- **Oficial confirmado:** trecho primário efetivamente lido, com URL, revisão ou data, condições e exceções.
- **Local:** o que o código/aula diz; não prova a mecânica do jogo.
- **Histórico secundário:** relato de outra pesquisa; precisa de reconsulta.
- **Inferência:** conclusão condicionada, com premissas explícitas.
- **Estratégia dos jogadores:** recomendação, sem status de regra.
- **Pendente:** informação ainda não recebida ou insuficiente.

Uma exportação verificável pode sustentar “documentado na revisão exportada”, mas não prova que essa seja a última versão online. A conclusão da coleta exige universo enumerado, leitura integral das páginas acessíveis e registro individual das exceções. Nenhuma aula, calculadora, fórmula, banco ou produção foi alterada.
